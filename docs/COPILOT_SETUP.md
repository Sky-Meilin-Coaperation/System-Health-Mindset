# GitHub Copilot Setup-Schritte für System Health Evolution

Diese Anleitung beschreibt die Einrichtung von GitHub Copilot für die lokale Entwicklung und das Repository **System Health Evolution** im Workspace.

---

## 1. Voraussetzungen
* Ein aktives GitHub-Konto mit Zugriff auf das Repository Sky-Meilin-Coaperation/System-Health-Mindset.
* Ein aktives GitHub Copilot Abonnement (Copilot Individual oder Copilot Business).
* **VS Code** installiert auf deinem Lenovo ThinkPad.

---

## 2. Installation der Erweiterung in VS Code
1. Öffne VS Code in deinem Workspace-Verzeichnis (C:\Workspace LM studio\SkyOS-Core-Operational-System).
2. Gehe in der linken Sidebar auf das **Extensions**-Icon (oder drücke Ctrl+Shift+X).
3. Suche nach **GitHub Copilot** und klicke auf **Install**.
4. Installiere direkt im Anschluss auch die Erweiterung **GitHub Copilot Chat** für die interaktive Chat-Unterstützung im Editor.

---

## 3. Authentifizierung bei GitHub
1. Nach der Installation erscheint unten rechts in VS Code eine Benachrichtigung zur Anmeldung.
2. Klicke auf **Sign in to GitHub**.
3. Der Browser öffnet sich automatisch – erlaube VS Code den Zugriff auf deinen GitHub-Account.
4. Sobald das Login erfolgreich ist, leuchtet das Copilot-Symbol unten rechts grün.

---

## 4. Nutzung im Workspace
* **Inline-Vorschläge:** Während du Code in Python, Markdown oder Dockerfiles schreibst, schlägt Copilot automatisch Code-Zeilen vor (annehmen mit der Tab-Taste).
* **Copilot Chat nutzen:** Drücke Ctrl+I im Editor oder öffne den Chat über das Seitenpanel, um gezielte Fragen zur Architektur, zu Docker-Containern oder zur Ollama-Anbindung zu stellen.
