# System-Health-Mindset

Ein zentraler Workspace für KI-Orchestrierung, Mindset-Methodik und System-Gesundheit.

## Einrichtung und Start
1. In den Arbeitsordner wechseln:
   ```powershell
   cd "C:\Users\Pascal\System-Health-Mindset"
   ```
2. Abhängigkeiten installieren:
   ```powershell
   python -m pip install -r REQUIREMENTS.txt
   ```
3. Anwendung starten:
   ```powershell
   python app.py
   ```
4. Danach im Browser öffnen:
   ```text
   http://127.0.0.1:8000
   ```

## Überblick
Das Projekt bündelt lokale KI-Orchestrierung, Gesundheits-Checks, systemische Diagnostik und experimentelle Agenten-Workflows in einem einzigen Workspace.

## Wichtige Dateien
- `app.py` – Haupt-Einstiegspunkt der FastAPI-Anwendung
- `REQUIREMENTS.txt` – Python-Abhängigkeiten
- `.env` – lokale Konfiguration und API-Umgebungswerte
- `GOVERNANCE.md` – Governance und Entscheidungsprozess
- `SECURITY.md` – Sicherheitsrichtlinien und Meldeprozess
