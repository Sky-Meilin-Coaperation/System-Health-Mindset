# Mitwirken an sky_app

Vielen Dank, dass du zu diesem Projekt beitragen möchtest! Egal ob Bugfixes, neue Funktionen oder Verbesserungen der Dokumentation – jede Hilfe ist willkommen.

## So kannst du mitwirken

1. **Forke das Repository** und klone es auf deinen Rechner.
2. Erstelle einen neuen Branch für deine Änderung (`git checkout -b feature/mein-feature`).
3. Führe deine Änderungen aus und teste sie.
4. Committe deine Änderungen (`git commit -m "feat: neues Feature hinzugefügt"`).
5. Pushe den Branch zu deinem Fork (`git push origin feature/mein-feature`).
6. Erstelle einen **Pull Request** auf GitHub.

## Richtlinien

* Halte den Code sauber und verständlich.
* Dokumentiere neue Funktionen kurz in der README oder den entsprechenden Dateien.
